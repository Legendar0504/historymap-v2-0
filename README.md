# Историческая карта

Школьный проект по истории (8 класс).

Карта мира с 1 по 2022 год. Двигаешь ползунок — меняется год, границы государств на карте,
а справа пишется, как называлась наша страна, кто ей правил, какие были события
и кто правил в других крупных странах.

## Как открыть

Скачать папку целиком и открыть файл `index.html` в браузере. Интернет не нужен.
Можно сразу открыть нужный год: `index.html#1812`.

## Что где лежит

- `index.html` — сама страница
- `style.css` — оформление
- `script.js` — работа карты и ползунка
- `dannye.js` — правители, столицы и события по годам
- `perevod.js` — названия государств по-русски
- `granicy/` — границы государств по годам (данные Cliopatria)
- `osnova.js` — суша, реки и озёра (Natural Earth)
- `leaflet/` — библиотека для карты

## Какие страны есть в списке правителей

Наша страна (с 862 года), Рим и Византия, Западная Римская империя, Франция, Англия,
Германия, Золотая Орда, Османская империя и Турция, Польша, Швеция, Арабский халифат,
Китай, США.
