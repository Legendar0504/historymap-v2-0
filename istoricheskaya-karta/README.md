# Историческая карта — версия на полных данных Cliopatria

Вторая версия карты. Первая (исправленная и переведённая) лежит в корне проекта.

Здесь границы взяты из Cliopatria целиком и без изменений:
- все годы: с 3400 года до н. э. по 2024 год;
- границы не упрощены;
- названия не переведены (по-английски);
- ошибки в данных не исправлены.

## Как открыть

Открыть `index.html` в браузере. Интернет не нужен.
Файлы большие, поэтому при смене эпохи карта может загружаться 1–2 секунды.

## Что где лежит

- `index.html`, `style.css`, `script.js` — страница, оформление и работа карты
- `dannye.js` — правители, столицы и события (с 1 года н. э.)
- `perevod.js` — здесь пустой: названия не переводятся
- `cliopatria/` — данные Cliopatria, разложенные по годам на 17 файлов (записи без изменений)
- `osnova.js` — суша, реки и озёра (Natural Earth)
- `leaflet/` — библиотека для карты

## Источники

- Границы: https://github.com/Seshat-Global-History-Databank/cliopatria
- Суша, реки и озёра: https://www.naturalearthdata.com
